📦 CodeLens (no computador)

Esta página já traz o projeto inteiro guardado dentro dela (295 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Instale o Node.js uma vez só: abra nodejs.org, baixe o botão LTS e instale clicando em Next até terminar. É de graça.
  2. Toque no botão verde acima. O arquivo CodeLens-local-09-10-c.zip vai para a pasta Downloads.
  3. Clique com o botão direito no zip → Extrair tudo → Extrair.
  4. Entre na pasta e dê dois cliques em iniciar.bat. Se o Windows avisar: Mais informações → Executar assim mesmo.
  5. Na 1ª vez demora. Depois o navegador abre sozinho.
  6. Para fechar: na janela preta, Ctrl + C. Não apague a pasta dados.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

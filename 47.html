Manual de instrução
  1. 🧭 Novo: Mapa de Rotas (no menu, ao lado da 🧹 Faxina). Compara o que a tela pede, o que o servidor tem e o que o manual diz (lê os .md do projeto, ou cole o trecho do manual). Mostra ✅ existe · ⚠️ nome parecido · ❌ não existe · 📘 só no manual. Conserta como teste (sempre com 📸 ponto de volta): ✏️ Trocar na tela o nome errado, e 🧩 Criar o plano B — quando o servidor não responde, a página responde sozinha: salva no aparelho e fala com o Gemini.
  2. É o formato de PC de antes, sem Python: pasta electron com main.cjs, terminal.cjs, ponte.cjs e preload.cjs (terminal do computador, ponte e pasta viva), package.json, a receita do GitHub e a pasta app com o Mini SK v28/10-C.
  3. Para virar o .exe: no Mini SK, abra este zip como projeto (🗂 Projetos → 🗜 Abrir pacote como projeto) e mande ao GitHub do Mini SK PC (🐙 GitHub). No GitHub: Actions → Programa .exe para Windows → Run workflow.
  4. Verde ✔: Artifacts → Mini-SK-Windows → Mini-SK-Instalar.exe. Ele atualiza o que você já tem e usa a mesma pasta Documentos\Mini-SK (seus projetos continuam lá).
  5. Novidades da v28/10-C: 🗜 abre .tar/.tar.gz/.tgz/.gz e 🧹 Faxina (lixo, segredos e histórico).
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

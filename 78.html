📦 Mini SK para PC v21/10-B

Esta página já traz o projeto inteiro guardado dentro dela (377 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Toque no botão verde acima para salvar o zip (no computador) e extraia.
  2. Na pasta Mini-SK-PC: barra de endereço → cmd → npm install → npm run programa.
  3. Lá em cima: v21/10-B e 💻 Terminal PC.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

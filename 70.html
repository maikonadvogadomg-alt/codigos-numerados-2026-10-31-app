📦 Mini SK v21/10-K (celular / PWA)

Esta página já traz o projeto inteiro guardado dentro dela (389 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Toque no botão verde acima para salvar o zip. Abra o index.html da pasta Mini-SK-21-10-K. Lá em cima vai aparecer v21/10-K.
  2. 💻 Mini SK no computador, sem Electron: abra o próprio Mini SK como projeto e toque em 🚀 Publicar → Tudo. O GitHub monta um .exe leve (em Python, igual ao do jurídico que abre).
  3. Esse .exe vem com: ⚡ Node funcionando de primeira · 💻 Terminal do computador de verdade (npm, node, python, git…) · 🔄 árvore ligada numa pasta de verdade (Documentos\Mini-SK): o que o terminal cria aparece sozinho na árvore · 🦙 Ollama.
  4. No computador: dois cliques no .exe. Abre uma janelinha preta pequena (é ela que liga tudo, pode minimizar) e o Mini SK numa janela própria. Para desligar, feche a janelinha.
  5. Se o Windows avisar "O Windows protegeu o computador": Mais informações → Executar assim mesmo.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

Esta página já traz o projeto inteiro guardado dentro dela (476 KB). Não precisa de internet para salvar.

Manual de instrução
  1. É o formato de PC de antes, sem Python: pasta electron com main.cjs, terminal.cjs, ponte.cjs e preload.cjs (terminal do computador, ponte e pasta viva), package.json, a receita do GitHub e a pasta app com o Mini SK v28/10-B.
  2. Para virar o .exe: no Mini SK, abra este zip como projeto (🗂 Projetos → 🗜 Abrir pacote como projeto) e mande ao GitHub do Mini SK PC (🐙 GitHub). No GitHub: Actions → Programa .exe para Windows → Run workflow.
  3. Verde ✔: Artifacts → Mini-SK-Windows → Mini-SK-Instalar.exe. Ele atualiza o que você já tem e usa a mesma pasta Documentos\Mini-SK (seus projetos continuam lá).
  4. Novidades da v28/10-B: 🗜 abre .tar/.tar.gz/.tgz/.gz e 🧹 Faxina (lixo, segredos e histórico).
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

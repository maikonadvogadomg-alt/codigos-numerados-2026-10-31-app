Manual de instrução
  1. É o mesmo jurídico que você roda no Mini SK (porta 5000), com tudo que já funcionava.
  2. 🦙 Novo: Ollama — IA grátis no próprio computador ou celular. Na tela principal, no seletor de IA (Pro/Flash/Própria), toque em 🦙 Ollama (grátis no aparelho) → 🦙 Ligar o Ollama → escolha o modelo (ou ⬇ baixe: no PC llama3.2:3b, no celular llama3.2:1b) → ✅ Usar o Ollama no jurídico.
  3. Vale para as ações jurídicas (Chave Própria) e para o chat Assistente. ↩ Voltar para o Gemini desfaz.
  4. Instalar: no Mini SK, abra o zip como projeto (🗂 Projetos → 🗜 Abrir pacote), mande para o Termux/pasta, rode npm install (só se pedir) e ligue com 🔁 Ligar o servidor sem cair (Mini SK v29/10-G) ou npm run dev.
  5. No computador ele não cai: deixe a janela do terminal aberta.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

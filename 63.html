📦 Assistente Jurídico 17/10-a — com APK e .exe prontos para o GitHub

Esta página já traz o projeto inteiro guardado dentro dela (686 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Toque no botão verde acima para salvar o Assistente-Juridico-modular-17-10-a.zip.
  2. Mande o projeto para um repositório do GitHub (pelo Mini SK: 🗂 Projetos → Abrir .zip como projeto → 🐙 GitHub → Enviar; ou pela Replit, se preferir). Confira antes que a prévia mostra o Assistente Jurídico.
  3. 📱 APK: no GitHub → aba Actions → 📱 Gerar APK (Android) → Run workflow. Em uns 10 minutos o APK aparece em Releases.
  4. 🖥️ .exe: no GitHub → aba Actions → Programa .exe para Windows → Run workflow. O instalador aparece em Releases.
  5. As receitas ficam na pasta .github/workflows do zip. Ela começa com ponto, por isso fica escondida no gerenciador de arquivos do celular — mas está lá.
  6. Seus documentos, modelos e conversas continuam: nada é apagado ao atualizar.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

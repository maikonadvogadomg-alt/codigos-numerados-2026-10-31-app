📦 Kit do VS Code: dividir e juntar

Esta página já traz o projeto inteiro guardado dentro dela (5 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Salve o zip no computador e extraia. Sai a pasta kit (com o dividir.py e o juntar.py).
  2. Copie a pasta kit para dentro da pasta do projeto e abra o projeto no VS Code.
  3. No terminal do VS Code: python kit/dividir.py index.html → cd index-modular → npx serve. Para voltar a um arquivo só: python kit/juntar.py index-modular.
  4. O passo a passo completo está no Manual do VS Code para modularizar.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

📦 Mini SK para PC (programa .exe) — 15/10

Esta página já traz o projeto inteiro guardado dentro dela (295 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Toque no botão verde acima para salvar o zip.
  2. Mini SK (celular) → importe o zip → 🐙 GitHub → mande para um repositório novo (ex.: minisk-pc).
  3. GitHub → Actions → Programa .exe para Windows → Run workflow. Espere uns 10 minutos.
  4. ✔ Verde: abra a execução → Artifacts → baixe Mini-SK-Windows. ✖ Vermelho: mande print do passo vermelho.
  5. No PC: dois cliques em Mini-SK-Instalar.exe. Se o Windows avisar: Mais informações → Executar assim mesmo.
  6. Como saber que é a versão do PC: no topo, o botão 📱 Termux vira 💻 Terminal PC, e ele já abre ligado.
  7. Ollama: 🤖 IA → ⚙️ Chaves → ＋ → no tipo, escolha Ollama (no seu PC, grátis — sem chave) → Buscar modelos.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

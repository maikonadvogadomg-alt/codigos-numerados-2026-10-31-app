💻 Mini SK para PC v31/10-D (Electron, com terminal)

Manual de instrução
  1. 🌐 Novo (31/10-D): Navegador de verdade. Botão 🌐 Navegador na barra de cima. No APK e no computador ele abre qualquer site aqui dentro (YouTube, GitHub, npm, Neon, Expo…), com ◀ ▶, endereço (pode digitar uma pesquisa), ↻ e ↗ para abrir no Chrome/Edge. Guarda os endereços que você usou. No celular, o voltar volta a página; na primeira página, fecha o navegador. Links de sites (ex.: nas respostas da IA) abrem nele. Para ter no APK, gere o APK de novo pelo 📦. No PWA comum os sites grandes proíbem aparecer dentro de outra página, então ele abre numa aba nova.
  2. 🩺 Novo (31/10-C) no computador: Saúde do computador. No 💻 Terminal, toque em 🩺 Saúde do computador: mostra espaço nos discos, memória, quem está usando cada porta (com ⏹ Fechar), as peças instaladas (Node, npm, Git, Ollama) e o tamanho de cada projeto. 🧹 Limpar só o que volta sozinho (temporários, cache do npm, peças node_modules — o seu código nunca é apagado). 💾 Fazer backup copia todos os projetos para a pasta que você escolher (ex.: o HD externo). 📋 Copiar manda o resumo para a IA ou para o Claude.
  3. 🎮 Mais bonito no computador: agora usa a placa de vídeo (se um dia abrir com a tela preta, ele desliga a placa sozinho e abre de novo). Barra de título escura. Botões 📱 Cara de celular (janela estreita, igual ao celular), 📟 Média e 🖥 Tela cheia. A janela abre do tamanho que você deixou.
  4. 💻 Novo (31/10-B) no computador: o instalador fecha sozinho o Mini SK antigo antes de instalar (acabou o "está sendo usado" no meio da instalação — não precisa mais desinstalar tudo). Ao fechar o Mini SK, ele para tudo o que o terminal ligou. O terminal e a ponte escolhem uma porta livre sozinhos. A porta da tela (7680) continua fixa de propósito: é nela que os seus projetos ficam guardados.
  5. ⛶ Novo (31/10-A): Tela cheia na visualização. No 📱 Termux (e no terminal do PC), ao lado de 👁 Visualizar tem ⛶ Tela cheia: o app aberto ocupa a tela inteira. Para sair: botão ✕ Sair da tela cheia (embaixo, à direita) ou o voltar do celular.
  6. 🎤🔊 Novo: o app aberto na visualização (ex.: o jurídico) agora pode usar o microfone (ditar) e o som. O celular pode perguntar "Permitir microfone?" → toque em Permitir.
  7. 🤖 Novo (F): quando a IA falha com o 🔁 Revezar ligado, aparece o erro de cada chave (ex.: "Gemini: limite do dia · OpenRouter: 401 User not found"). 401 / User not found = chave apagada ou trocada no site → tire ela em ⚙️ Chaves.
  8. 🧪 Testar API: chamadas para outro servidor (ex.: o Ollama do computador) aparecem como 🌐 de outro servidor, e não mais como "rota não achada".
  9. 🛡 Consertado (E): "package.json vazio" / EJSONPARSE. Quando a pasta do projeto no computador tinha arquivos vazios (ex.: copiados do OneDrive), a pasta viva copiava o vazio por cima da árvore. Agora: arquivo vazio na pasta nunca apaga o conteúdo da árvore, e numa pasta que o Mini SK ainda não conhece quem manda é a árvore.
  10. 🙈 Os botões de comandos de pastas de sobra (_sobras-do-replit, ex.: "push-force", que mexe no banco) não aparecem mais.
  11. 🔧 Consertado (D): o erro "vite não é reconhecido" acontecia porque uma instalação anterior tinha quebrado no meio — a pasta de peças existia, mas sem o vite, e o 🚀 Ligar tudo achava que já estava instalado. Agora ele confere a peça de verdade e, se faltar, instala de novo antes de ligar.
  12. 🤖 Novo (C): a IA enxerga o terminal. No terminal (PC e Termux) tem o botão 🤖 Perguntar à IA: manda as últimas linhas (o erro) para a IA, que responde o que fazer em passos simples. Na 🤖 IA, a caixinha 💻 Terminal faz ela ver o terminal em toda pergunta.
  13. 🔁 Atualizar o programa no PC: rode o Mini-SK-Instalar.exe novo — ele substitui o antigo sozinho (mesmo nome, seus projetos ficam). Não precisa renomear. Se disser que está em uso, feche o Mini SK antes. Se o arquivo baixar como "Mini-SK-Instalar (1).exe", tudo bem: é só abrir esse.
  14. ⏳ Novo (B): no computador, o npm install (no 🚀 Ligar tudo e no botão 📦) agora mostra cada peça baixando — antes parecia travado por 3 minutos. E já resolve o erro mais comum (peças que brigam: ERESOLVE).
  15. 💻 Terminal do computador igual ao do Termux: 🚀 Ligar tudo (instala as peças se faltar e liga o projeto com o comando certo — no jurídico antigo, o servidor da porta 5000), ⏹ Parar, 🦙 Ligar o Ollama e 👁 Visualizar com os botões de porta (5173, 5000, 3000…) e campo para digitar a porta.
  16. 📁 Os projetos ficam em C:\Mini-SK (fora de Documentos, longe do OneDrive). Na 1ª vez cada projeto precisa do 🚀 Ligar tudo de novo (instala as peças).
  17. ◀ ▶ setas na barra de cima e a roda do mouse rola os botões.
  18. 🐙 Projetos no GitHub igual à Replit (lista, pesquisa, ⬇ Abrir, ⬆ Mandar todos, 🧹 Liberar espaço) — em 🗂 Projetos.
  19. ⚠ O terminal só existe no programa (.exe). Abrindo o index.html pelo navegador, aparece o painel do Termux e nada roda. Para o .exe: abra este zip como projeto no Mini SK → 🐙 GitHub → envie → no GitHub: Actions → Programa .exe para Windows → Run workflow → Artifacts → Mini-SK-Windows → Mini-SK-Instalar.exe.

Manual de instrução
  1. 🔧 Consertado (D): o erro "vite não é reconhecido" acontecia porque uma instalação anterior tinha quebrado no meio — a pasta de peças existia, mas sem o vite, e o 🚀 Ligar tudo achava que já estava instalado. Agora ele confere a peça de verdade e, se faltar, instala de novo antes de ligar.
  2. 🤖 Novo (C): a IA enxerga o terminal. No terminal (PC e Termux) tem o botão 🤖 Perguntar à IA: manda as últimas linhas (o erro) para a IA, que responde o que fazer em passos simples. Na 🤖 IA, a caixinha 💻 Terminal faz ela ver o terminal em toda pergunta.
  3. ⏳ Novo (B): no computador, o npm install (no 🚀 Ligar tudo e no botão 📦) agora mostra cada peça baixando — antes parecia travado por 3 minutos. E já resolve o erro mais comum (peças que brigam: ERESOLVE).
  4. 🐙 Novo: projetos no GitHub, igual ao SK da Replit. Em 🗂 Projetos, com o token do GitHub (ou trazido pelo ⚙️ → 🔐 Cofre), aparece a lista dos seus repositórios — mais recentes primeiro, ⤓ Mais antigos e 🔎 pesquisa (Enter procura em todos). Eles não ocupam espaço: ⬇ Abrir baixa e abre na hora.
  5. Cada projeto do aparelho mostra: ✅ igual no GitHub, ✏️ mudou (falta ⬆ Enviar) ou ⚠ só neste aparelho. ⬆ Mandar os N para o GitHub cria repositórios privados (só você vê) e nunca apaga nada lá.
  6. 🧹 Liberar espaço: tira do aparelho só os projetos que já estão iguais no GitHub (voltam com ⬇ Abrir). O 💾 Backup de tudo pergunta se deixa de fora os que já estão no GitHub — fica leve.
  7. ◀ ▶ Novo: setas na barra de cima para ver os outros botões (no computador também rola com a roda do mouse).
  8. Instalar: abra o zip como projeto no Mini SK atual ou publique como sempre. O selo deve mostrar v30/10-D.

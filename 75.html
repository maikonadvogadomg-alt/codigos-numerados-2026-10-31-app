📦 Mini SK v21/10-G (celular / PWA)

Esta página já traz o projeto inteiro guardado dentro dela (379 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Toque no botão verde acima para salvar o zip. Lá em cima vai aparecer v21/10-G.
  2. 💻 Novo: abra o próprio Mini SK como projeto e toque em 🚀 Publicar → Tudo. O .exe sai como o Mini SK para PC com o terminal do computador (não pede mais Termux), com a ponte e a pasta viva. E já vem sem a tela preta.
  3. ⚡ Node: a tela do servidor aparece sozinha abaixo do terminal. 🐞 explica os erros "Missing script" e "electron".
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

Manual de instrução
  1. Toque no botão verde acima para salvar o Mini-SK-09-10-b.zip.
  2. Entre em app.netlify.com → o seu site do Mini SK → aba Deploys → arraste o zip (ou toque para escolher o arquivo).
  3. Abra o site no Chrome. No topo deve aparecer v09/10-b.
  4. Para instalar: menu ⋮ → Instalar app.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.

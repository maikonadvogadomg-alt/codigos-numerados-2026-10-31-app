Manual de instrução
  1. 💻 Terminal do computador igual ao do Termux: 🚀 Ligar tudo (instala as peças se faltar e liga o projeto com o comando certo — no jurídico antigo, o servidor da porta 5000), ⏹ Parar, 🦙 Ligar o Ollama e 👁 Visualizar com os botões de porta (5173, 5000, 3000…) e campo para digitar a porta.
  2. 📁 Os projetos ficam em C:\Mini-SK (fora de Documentos, longe do OneDrive). Na 1ª vez cada projeto precisa do 🚀 Ligar tudo de novo (instala as peças).
  3. ◀ ▶ setas na barra de cima e a roda do mouse rola os botões.
  4. 🐙 Projetos no GitHub igual à Replit (lista, pesquisa, ⬇ Abrir, ⬆ Mandar todos, 🧹 Liberar espaço) — em 🗂 Projetos.
  5. ⚠ O terminal só existe no programa (.exe). Abrindo o index.html pelo navegador, aparece o painel do Termux e nada roda. Para o .exe: abra este zip como projeto no Mini SK → 🐙 GitHub → envie → no GitHub: Actions → Programa .exe para Windows → Run workflow → Artifacts → Mini-SK-Windows → Mini-SK-Instalar.exe.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

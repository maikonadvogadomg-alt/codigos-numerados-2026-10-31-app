Manual de instrução
  1. É o Mini SK para PC (Electron, sem Python): pasta electron com main.cjs, terminal.cjs, ponte.cjs e preload.cjs, package.json, a receita do GitHub e a pasta app com o Mini SK v29/10-E.
  2. 🔐 Novo: Cofre de chaves (ver, copiar, baixar só as chaves com senha). 🌐 Também: no PC, a IA pesquisa na internet pelo próprio programa (sem bloqueio). 📷 A IA vê prints e fotos. 📦 O APK que ele gera sai com todas as autorizações.
  3. Para virar o .exe: no Mini SK, abra este zip como projeto (🗂 Projetos → 🗜 Abrir pacote como projeto) e mande ao GitHub do Mini SK PC (🐙 GitHub). No GitHub: Actions → Programa .exe para Windows → Run workflow.
  4. Verde ✔: Artifacts → Mini-SK-Windows → Mini-SK-Instalar.exe.
  5. 📦 Novo (D): o APK não perde o lugar quando você sai para baixar algo e volta. Ele abre sempre a mesma janela (não começa do zero), pede uma vez "sem restrição de bateria" (toque em Permitir; assim o Android não fecha o app no fundo) e marca os dados como persistentes (o Android não apaga para liberar espaço). Gere o APK de novo para ter.
  6. ⬅ Novo (E): botão VOLTAR do celular no APK. Agora ele fecha a janelinha ou o painel que estiver aberto, volta para a tela anterior e, na primeira tela, não fecha mais o app (só vai para o fundo; quando você volta, está tudo igual). Vale para qualquer página que vira APK pelo Mini SK — Meu Chat, jurídico, o próprio Mini SK. Gere o APK de novo para ter. Continua com o seu ícone e cores.

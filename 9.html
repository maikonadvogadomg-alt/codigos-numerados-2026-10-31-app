Manual de instrução
  1. 🤖 Novo (F): quando a IA falha com o 🔁 Revezar ligado, aparece o erro de cada chave (ex.: "Gemini: limite do dia · OpenRouter: 401 User not found"). 401 / User not found = chave apagada ou trocada no site → tire ela em ⚙️ Chaves.
  2. 🧪 Testar API: chamadas para outro servidor (ex.: o Ollama do computador) aparecem como 🌐 de outro servidor, e não mais como "rota não achada".
  3. 🛡 Consertado (E): "package.json vazio" / EJSONPARSE. Quando a pasta do projeto no computador tinha arquivos vazios (ex.: copiados do OneDrive), a pasta viva copiava o vazio por cima da árvore. Agora: arquivo vazio na pasta nunca apaga o conteúdo da árvore, e numa pasta que o Mini SK ainda não conhece quem manda é a árvore.
  4. 🙈 Os botões de comandos de pastas de sobra (_sobras-do-replit, ex.: "push-force", que mexe no banco) não aparecem mais.
  5. 🔧 Consertado (D): o erro "vite não é reconhecido" acontecia porque uma instalação anterior tinha quebrado no meio — a pasta de peças existia, mas sem o vite, e o 🚀 Ligar tudo achava que já estava instalado. Agora ele confere a peça de verdade e, se faltar, instala de novo antes de ligar.
  6. 🤖 Novo (C): a IA enxerga o terminal. No terminal (PC e Termux) tem o botão 🤖 Perguntar à IA: manda as últimas linhas (o erro) para a IA, que responde o que fazer em passos simples. Na 🤖 IA, a caixinha 💻 Terminal faz ela ver o terminal em toda pergunta.
  7. 🔁 Atualizar o programa no PC: rode o Mini-SK-Instalar.exe novo — ele substitui o antigo sozinho (mesmo nome, seus projetos ficam). Não precisa renomear. Se disser que está em uso, feche o Mini SK antes. Se o arquivo baixar como "Mini-SK-Instalar (1).exe", tudo bem: é só abrir esse.
  8. ⏳ Novo (B): no computador, o npm install (no 🚀 Ligar tudo e no botão 📦) agora mostra cada peça baixando — antes parecia travado por 3 minutos. E já resolve o erro mais comum (peças que brigam: ERESOLVE).
  9. 💻 Terminal do computador igual ao do Termux: 🚀 Ligar tudo (instala as peças se faltar e liga o projeto com o comando certo — no jurídico antigo, o servidor da porta 5000), ⏹ Parar, 🦙 Ligar o Ollama e 👁 Visualizar com os botões de porta (5173, 5000, 3000…) e campo para digitar a porta.
  10. 📁 Os projetos ficam em C:\Mini-SK (fora de Documentos, longe do OneDrive). Na 1ª vez cada projeto precisa do 🚀 Ligar tudo de novo (instala as peças).
  11. ◀ ▶ setas na barra de cima e a roda do mouse rola os botões.
  12. 🐙 Projetos no GitHub igual à Replit (lista, pesquisa, ⬇ Abrir, ⬆ Mandar todos, 🧹 Liberar espaço) — em 🗂 Projetos.
  13. ⚠ O terminal só existe no programa (.exe). Abrindo o index.html pelo navegador, aparece o painel do Termux e nada roda. Para o .exe: abra este zip como projeto no Mini SK → 🐙 GitHub → envie → no GitHub: Actions → Programa .exe para Windows → Run workflow → Artifacts → Mini-SK-Windows → Mini-SK-Instalar.exe.

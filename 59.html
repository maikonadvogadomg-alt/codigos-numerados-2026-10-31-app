Manual de instrução
  1. Toque no botão verde para salvar o zip. Abra o index.html da pasta Meu-Chat, do jeito que você abre o Mini SK. Lá em cima: v27/10-A.
  2. Primeira vez: toque em ⚙️, cole uma chave grátis do Gemini (aistudio.google.com/apikey) e toque em Guardar chave. Pode pôr várias: quando uma chega no limite, ele passa sozinho para a próxima.
  3. Para virar app: menu ⋮ do Chrome → Instalar app. No app instalado o 🎤 microfone funciona.
  4. Tem: 🎤 falar · 🔊 voz natural (não é a de robô) · 🙌 mãos livres · 📷 foto e print · 🌐 internet · 🔗 ler links · 🧠 memória · 👁 ver código HTML/TSX funcionando · 💾 backup que não apaga nada.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

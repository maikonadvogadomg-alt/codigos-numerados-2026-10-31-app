📦 Assistente Jurídico COMPLETO — um .exe só, sem .bat

Esta página já traz o projeto inteiro guardado dentro dela (360 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Toque no botão verde acima para salvar o zip. (Lembre: primeiro baixe esta página pelo chat e abra ela no Chrome.)
  2. Abra o Mini SK → importe esse zip como projeto → 🐙 GitHub → mande para um repositório novo (ex.: juridico-completo).
  3. No site do GitHub, nesse repositório: aba Actions → Programa .exe para Windows → Run workflow.
  4. Espere 10 a 15 minutos. O GitHub liga o servidor e o programa e confere se respondem. Se algo falhar, fica ✖ vermelho: mande um print do passo vermelho.
  5. Ficou ✔ verde: na página do repositório, à direita, Releases → baixe Assistente-Juridico.exe. É um arquivo só.
  6. No computador: dois cliques. Sem .bat, sem instalar Node. Se o Windows avisar: Mais informações → Executar assim mesmo. Se der erro, mande o arquivo Documentos\Assistente-Juridico\registro.txt.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

📦 Assistente Jurídico — programa .exe

Esta página já traz o projeto inteiro guardado dentro dela (361 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Toque no botão verde acima para salvar o zip.
  2. Abra o Mini SK → importe esse zip → 🐙 GitHub → mande para um repositório novo (ex.: juridico).
  3. No site do GitHub, nesse repositório: aba Actions → Programa .exe para Windows → Run workflow → Run workflow verde.
  4. Espere 10 a 15 minutos. O próprio GitHub liga o programa e confere se funciona antes de entregar.
  5. Ficou ✔ verde: toque na execução → desça até Artifacts → baixe Assistente-Juridico-Windows. Ficou ✖ vermelho: abra o passo vermelho e mande um print.
  6. No computador: abra o zip baixado e dê dois cliques em Assistente-Juridico-Instalar.exe. Ele cria o ícone na área de trabalho. Se o Windows avisar: Mais informações → Executar assim mesmo.
  7. Pronto: abre numa janela própria, sem .bat, sem janela preta e sem instalar o Node. Seus dados ficam em Documentos\Assistente-Juridico.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

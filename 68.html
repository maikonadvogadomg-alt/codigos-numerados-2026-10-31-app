📦 Assistente Jurídico (no computador)

Esta página já traz o projeto inteiro guardado dentro dela (361 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Instale o Node.js uma vez só: abra nodejs.org, baixe o botão LTS e instale clicando em Next até terminar. É de graça.
  2. Toque no botão verde acima. O arquivo Assistente-Juridico-local-09-10-b.zip vai para a pasta Downloads.
  3. Na pasta Downloads, clique com o botão direito no zip → Extrair tudo → Extrair.
  4. Entre na pasta extraída e dê dois cliques em iniciar.bat. Se o Windows avisar "protegeu o computador": Mais informações → Executar assim mesmo.
  5. Na 1ª vez demora uns minutos (ele instala as peças). Depois o navegador abre sozinho no endereço que aparece na janela preta.
  6. Para fechar: na janela preta, aperte Ctrl + C e espere. Seus dados ficam na pasta dados: nunca apague essa pasta.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

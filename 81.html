Esta página já traz o projeto inteiro guardado dentro dela (376 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Toque no botão verde acima para salvar o Caca-Bug.zip.
  2. Entre em app.netlify.com → o site do Caça-Bug (ou Add new site → Deploy manually) → arraste o zip.
  3. Abra no Chrome → menu ⋮ → Instalar app.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

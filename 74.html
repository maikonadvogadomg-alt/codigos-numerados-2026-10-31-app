📦 Mini SK para PC v21/10-H

Esta página já traz o projeto inteiro guardado dentro dela (390 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Este é só para o computador. Salve o zip e extraia.
  2. Dentro da pasta Mini-SK-PC, clique na barra de endereço, digite cmd, depois npm install e npm run programa. Lá em cima vai aparecer v21/10-H.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

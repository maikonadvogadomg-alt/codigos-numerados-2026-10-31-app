Esta página já traz o projeto inteiro guardado dentro dela (197 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Toque no botão verde acima para salvar o zip.
  2. No celular (site/app): Netlify → o site do jurídico (ou app.netlify.com/drop) → arraste o zip. Seus documentos continuam.
  3. No computador (programa .exe, usa o Ollama): Mini SK → 🗂 Projetos → Abrir .zip como projeto → este zip → 📦 APK → repositório juridico-pc → 🖥️ Enviar e gerar .exe → baixar o Assistente-Juridico-Instalar.exe → dois cliques.
  4. 📜 Regras e memória (aba nova): cole aqui as regras do seu jurídico antigo, uma por vez ou tudo de uma vez. Ligue/desligue quando quiser. As ⚡ Minhas ações viram botões no ⚡ Processar.
  5. 🦙 Ollama no computador: ⚙️ Config → Qual IA usar → Ollama → 🧪 Testar o Ollama.
  6. 🌐 Internet: marque "pesquisar na internet" no ⚡ Processar ou na 💬 Conversa (funciona com o Gemini).
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

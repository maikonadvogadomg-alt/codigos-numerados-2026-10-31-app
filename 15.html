Manual de instrução
  1. 🐙 Novo: projetos no GitHub, igual ao SK da Replit. Em 🗂 Projetos, com o token do GitHub (ou trazido pelo ⚙️ → 🔐 Cofre), aparece a lista dos seus repositórios — mais recentes primeiro, ⤓ Mais antigos e 🔎 pesquisa (Enter procura em todos). Eles não ocupam espaço: ⬇ Abrir baixa e abre na hora.
  2. Cada projeto do aparelho mostra: ✅ igual no GitHub, ✏️ mudou (falta ⬆ Enviar) ou ⚠ só neste aparelho. ⬆ Mandar os N para o GitHub cria repositórios privados (só você vê) e nunca apaga nada lá.
  3. 🧹 Liberar espaço: tira do aparelho só os projetos que já estão iguais no GitHub (voltam com ⬇ Abrir). O 💾 Backup de tudo pergunta se deixa de fora os que já estão no GitHub — fica leve.
  4. ◀ ▶ Novo: setas na barra de cima para ver os outros botões (no computador também rola com a roda do mouse).
  5. Instalar: abra o zip como projeto no Mini SK atual ou publique como sempre. O selo deve mostrar v30/10-A.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.

Manual de instrução
  1. 🩺 Novo (31/10-C) no computador: Saúde do computador. No 💻 Terminal, toque em 🩺 Saúde do computador: mostra espaço nos discos, memória, quem está usando cada porta (com ⏹ Fechar), as peças instaladas (Node, npm, Git, Ollama) e o tamanho de cada projeto. 🧹 Limpar só o que volta sozinho (temporários, cache do npm, peças node_modules — o seu código nunca é apagado). 💾 Fazer backup copia todos os projetos para a pasta que você escolher (ex.: o HD externo). 📋 Copiar manda o resumo para a IA ou para o Claude.
  2. 🎮 Mais bonito no computador: agora usa a placa de vídeo (se um dia abrir com a tela preta, ele desliga a placa sozinho e abre de novo). Barra de título escura. Botões 📱 Cara de celular (janela estreita, igual ao celular), 📟 Média e 🖥 Tela cheia. A janela abre do tamanho que você deixou.
  3. 💻 Novo (31/10-B) no computador: o instalador fecha sozinho o Mini SK antigo antes de instalar (acabou o "está sendo usado" no meio da instalação — não precisa mais desinstalar tudo). Ao fechar o Mini SK, ele para tudo o que o terminal ligou. O terminal e a ponte escolhem uma porta livre sozinhos. A porta da tela (7680) continua fixa de propósito: é nela que os seus projetos ficam guardados.
  4. ⛶ Novo (31/10-A): Tela cheia na visualização. No 📱 Termux (e no terminal do PC), ao lado de 👁 Visualizar tem ⛶ Tela cheia: o app aberto ocupa a tela inteira. Para sair: botão ✕ Sair da tela cheia (embaixo, à direita) ou o voltar do celular.
  5. 🎤🔊 Novo: o app aberto na visualização (ex.: o jurídico) agora pode usar o microfone (ditar) e o som. O celular pode perguntar "Permitir microfone?" → toque em Permitir.
  6. 🤖 Novo (F): quando a IA falha com o 🔁 Revezar ligado, aparece o erro de cada chave (ex.: "Gemini: limite do dia · OpenRouter: 401 User not found"). 401 / User not found = chave apagada ou trocada no site → tire ela em ⚙️ Chaves.
  7. 🧪 Testar API: chamadas para outro servidor (ex.: o Ollama do computador) aparecem como 🌐 de outro servidor, e não mais como "rota não achada".
  8. 🛡 Consertado (E): "package.json vazio" / EJSONPARSE. Quando a pasta do projeto no computador tinha arquivos vazios (ex.: copiados do OneDrive), a pasta viva copiava o vazio por cima da árvore. Agora: arquivo vazio na pasta nunca apaga o conteúdo da árvore, e numa pasta que o Mini SK ainda não conhece quem manda é a árvore.
  9. 🙈 Os botões de comandos de pastas de sobra (_sobras-do-replit, ex.: "push-force", que mexe no banco) não aparecem mais.
  10. 🔧 Consertado (D): o erro "vite não é reconhecido" acontecia porque uma instalação anterior tinha quebrado no meio — a pasta de peças existia, mas sem o vite, e o 🚀 Ligar tudo achava que já estava instalado. Agora ele confere a peça de verdade e, se faltar, instala de novo antes de ligar.
  11. 🤖 Novo (C): a IA enxerga o terminal. No terminal (PC e Termux) tem o botão 🤖 Perguntar à IA: manda as últimas linhas (o erro) para a IA, que responde o que fazer em passos simples. Na 🤖 IA, a caixinha 💻 Terminal faz ela ver o terminal em toda pergunta.
  12. ⏳ Novo (B): no computador, o npm install (no 🚀 Ligar tudo e no botão 📦) agora mostra cada peça baixando — antes parecia travado por 3 minutos. E já resolve o erro mais comum (peças que brigam: ERESOLVE).
  13. 🐙 Novo: projetos no GitHub, igual ao SK da Replit. Em 🗂 Projetos, com o token do GitHub (ou trazido pelo ⚙️ → 🔐 Cofre), aparece a lista dos seus repositórios — mais recentes primeiro, ⤓ Mais antigos e 🔎 pesquisa (Enter procura em todos). Eles não ocupam espaço: ⬇ Abrir baixa e abre na hora.
  14. Cada projeto do aparelho mostra: ✅ igual no GitHub, ✏️ mudou (falta ⬆ Enviar) ou ⚠ só neste aparelho. ⬆ Mandar os N para o GitHub cria repositórios privados (só você vê) e nunca apaga nada lá.
  15. 🧹 Liberar espaço: tira do aparelho só os projetos que já estão iguais no GitHub (voltam com ⬇ Abrir). O 💾 Backup de tudo pergunta se deixa de fora os que já estão no GitHub — fica leve.
  16. ◀ ▶ Novo: setas na barra de cima para ver os outros botões (no computador também rola com a roda do mouse).
  17. Instalar: abra o zip como projeto no Mini SK atual ou publique como sempre. O selo deve mostrar v31/10-C.
